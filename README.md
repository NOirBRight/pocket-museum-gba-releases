# Pocket Museum - GBA

只做 GBA 的 Android 启动器：以卡带收藏浏览游戏，内置模拟器游玩。免费、非商用。此仓库只存发行说明与更新清单，实现源码保持私有。

目录数据包、图片媒体包、金手指数据包和安装包在 Releases 分开发行；数据包不含游戏 ROM。媒体包继续支持本地导入，没有媒体时应用仍可浏览与游玩。

这一批只提供目录数据包和金手指数据包。安装包和图片媒体包暂未通过本渠道提供。应用内更新入口仍在开发。检查和下载只在用户主动选择时进行，不上传 ROM、文件名或游戏库，不提供 Pocket Museum 账号服务。GitHub 可达性和下载速度没有保证，失败可重试，已有离线内容仍可用。

更新入口为根目录 `updates.json`，契约见 [manifest-v1.md](manifest-v1.md)。下载后须核对大小、SHA-256。安装包另行提供时，还须核验正式包名 `com.pocketmuseum.gba`、版本及原正式证书，再由 Android 安装器确认。

开源组件、修改源码及重建材料见 [公开源码材料](https://github.com/NOirBRight/pocket-museum-gba-oss)。许可证、署名与数据来源随本批提供的数据包提供；图片版权属于各游戏开发商和发行商。本仓库不为实现源码或第三方图片授予新的许可。

此发行渠道目前不包含视频；视频方案单独决定。
